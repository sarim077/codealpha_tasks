# CodeAlpha Frontend Internship - Task 2: Build a Calculator

A glassmorphic calculator created using HTML, CSS, and vanilla JavaScript.

## 🚀 Features
- **Arithmetic Operations:** Addition (+), Subtraction (−), Multiplication (×), Division (÷).
- **Extra Math Utilities:** Percentage (`%`), Sign toggle (`±`), Decimals (`.`).
- **Screen & Display:** Real-time formula preview, commas for large numbers, auto-scaling font size for overflow prevention.
- **Error Handling:** Division-by-zero protection.
- **Interactive History Panel (Bonus):** Click the clock icon to slide out previous calculation logs; click any past result to load it straight into the current screen.
- **Full Physical Keyboard Support (Bonus):**
  - Numbers `0` - `9`
  - Operators `+`, `-`, `*`, `/`
  - Calculate `Enter` or `=`
  - Delete `Backspace`
  - Clear `Escape`
  - Percent `%`

## 📁 Project Structure
- `index.html` - App markup and keypad structure.
- `style.css` - Glassmorphism, CSS grid layout, animations, and color scheme.
- `script.js` - Calculator engine class, event delegation, and history log management.

## 💻 How to Run
Simply open `index.html` in your browser.
