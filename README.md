# CodeAlpha - Frontend Development Internship Tasks

Repository containing solutions for the CodeAlpha Frontend Development Internship tasks.

## 📌 Projects Included

### 1. [Task 1: Image Gallery & Lightbox Viewer](./Task1_Image_Gallery/)
- Dynamic responsive image grid with modern hover effects.
- Modal lightbox preview with Previous/Next controls, image counter, and high-resolution link.
- Filter images by category: Nature, Architecture, Technology, and Travel.
- Full keyboard navigation (`Escape`, `ArrowLeft`, `ArrowRight`).

### 2. [Task 2: Smart Glassmorphic Calculator](./Task2_Calculator/)
- Responsive calculator with arithmetic operations (`+`, `−`, `×`, `÷`), sign toggle (`±`), and percentages (`%`).
- Real-time expression display and auto-scaling font for overflow handling.
- Calculation history drawer allowing users to review and restore past results.
- Keyboard support (`0-9`, `+`, `-`, `*`, `/`, `Enter`, `Backspace`, `Escape`).

### 3. [Task 4: AuraWave Music Player](./Task4_Music_Player/)
- Modern music player with audio controls (Play, Pause, Next, Previous).
- Live track duration, interactive progress scrubber, volume slider, and instant mute toggle.
- Rotating vinyl disc animation and audio wave equalizer visualizer.
- Playlist modal queue, autoplay next track, shuffle mode, and repeat mode.
- Keyboard shortcuts (`Space`, `ArrowLeft`, `ArrowRight`).

## 🛠️ Tech Stack
- HTML5 (Semantic Structure)
- CSS3 (Flexbox, CSS Grid, Glassmorphism, Animations, Media Queries)
- Vanilla JavaScript (DOM Manipulation, Web Audio API, Event Delegation)
