# CodeAlpha Frontend Internship - Task 1: Image Gallery

A responsive, interactive image gallery with filtering, smooth hover animations, and a rich lightbox modal viewer.

## 🚀 Features
- **Responsive Layout:** CSS Grid adapting cleanly from mobile phones to high-resolution desktop screens.
- **Lightbox Viewer:** Click any image to view in full resolution with descriptive title and caption.
- **Navigation Controls:** Prev/Next buttons, live item counter (`1 / 8`), and direct link to high-res capture.
- **Keyboard Navigation:** Full support for `Escape` (exit), `ArrowLeft` (previous image), and `ArrowRight` (next image).
- **Category Filter (Bonus):** Filter images seamlessly across `All`, `Nature`, `Architecture`, `Technology`, and `Travel`.
- **Modern Glassmorphism UI:** Neon glow accents, smooth hover zooms, and blurred backdrop overlay.

## 📁 Project Structure
- `index.html` - Semantic layout and modal overlay.
- `style.css` - Custom design, grid system, transitions, and responsive queries.
- `script.js` - Data list, category filtering logic, keyboard bindings, and modal controls.

## 💻 How to Run
Simply open `index.html` in any modern web browser or use a live server extension.
