# CodeAlpha Frontend Internship - Task 4: Music Player using JavaScript

A music player web application designed with HTML, modern CSS glassmorphism, and vanilla JavaScript.

## 🚀 Features
- **Audio Controls:** Full HTML5 Audio playback (Play, Pause, Next track, Previous track).
- **Track Metadata:** Shows live track title, artist name, music genre tag, and high-resolution album cover art.
- **Dynamic Track Progress Bar:** Click or seek anywhere along the timeline with formatted timestamps (`MM:SS`).
- **Volume & Mute Control:** Fine-grain slider with percentage indicator and instant mute toggle button.
- **Interactive Playlist Drawer (Bonus):** Toggleable queue with track list and one-click play.
- **Autoplay & Playback Modes (Bonus):** Continuous playback to next song, random Shuffle mode, and Repeat mode.
- **Animations:** Spinning vinyl disc animation and audio equalizer wave visualization while playing.
- **Keyboard Shortcuts:** `Space` (Play/Pause), `ArrowRight` (Next Track), `ArrowLeft` (Previous Track).

## 📁 Project Structure
- `index.html` - Audio markup, rotating vinyl stage, visualizer, and control buttons.
- `style.css` - Custom styling, disc spin animation, visualizer bars, and responsive layout.
- `script.js` - Audio API integration, queue controls, scrubber logic, and event listeners.

## 💻 How to Run
Simply open `index.html` in your web browser.
